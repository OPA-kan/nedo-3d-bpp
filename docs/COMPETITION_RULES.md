# NEDO Challenge コンペルール要約

**対象:** NEDO Challenge, Baggage-Loading Robot コンテスト2

**資料:** ユーザー提供のSIGNATE課題ページ本文（2026-07-28受領）

**位置づけ:** 競技要件の要約。実装詳細は公式配布シミュレータのソースを優先する。

## 1. エージェントの入出力

エージェントは、次の2機能を状況に応じて提供する。

### オフライン最適化

- 入力: 最大2コンテナ分の全手荷物。寸法、質量、soft、priorityなどを含む。
- 出力: 積み付け順を表す手荷物index列。
- 制限時間: 評価環境で3分。
- timeout時: 入力された元の順序が採用される。

### オンライン最適化

- 入力: 観測可能な手荷物poolと、各コンテナの現在状態。
- 出力: pool内の手荷物、対象コンテナ、3D座標、姿勢。
- 制限時間: 評価環境で1 actionあたり8秒。
- timeout時: ランダムactionが強制実行される。

## 2. 評価シナリオ

| 課題 | offline | online pool | 主な条件 |
|---|---|---:|---|
| A | あり | 1 | 全体順序を事前計算。約40個（1台）または約80個（2台） |
| B | なし | 約3〜40 | 小規模buffer内で逐次選択 |
| C | なし | 1 | 到着順どおりに逐次配置 |

各課題では次の組合せが出題される。

- コンテナ1台または2台
- 棚あり・なし
- 空または既配置手荷物ありの初期状態
- priority専用コンテナ指定あり・なし
- 通常、soft、priority手荷物
- Aではofflineの順序が固定された後にonlineを実行

対象コンテナはLD3規格のAKE/AKNを基にした形状で、片側の切欠き、棚、
最大2台の同時運用を含む。

## 3. 1 actionごとの失敗条件

次のいずれかがNGなら、その配置は無効または失敗となる。

1. action形式、index、座標、姿勢が許容範囲外
2. 手荷物がコンテナ内に完全包含されない
3. 開口部から目標までの搬入経路で、既配置荷物・壁・棚と干渉する
4. 搬入時に他物体へ1.5 cmより近づく
5. 配置後の物理settleで、滑落または大きな崩れが生じる

手荷物は目標位置の8 cm上から落とす。全荷物を配置するか、配置に失敗した時点で
そのsceneを終了し、その状態を総合評価する。

幾何判定の実装値と座標系は `docs/GEOMETRY_RULES.md` を正本とする。

## 4. 積付完了後の総合評価

コンペの総合評価は、少なくとも次を含む重み付き評価である。

- 有効コンテナ容積に対する空間充填率
- 質量を考慮した重心の低さ
- priority手荷物の下敷き、指定コンテナ違反
- soft手荷物の上への通常荷物配置による破損リスク
- 蓋を閉じて重力を変動させる動的安定性テスト
  - 初期位置からのずれ
  - 手荷物へ加わる力
  - 運動エネルギー

sceneごとの評価項目を重み付き平均し、評価scene全体の平均を100点満点の
スクリーニング評価とする。

## 5. ローカルscoreの解釈

このリポジトリに固定されたシミュレータの `evaluator.py` が直接出力する主な値は、
`fill_score` と `num_placed_items` である。したがって、
`reports/lookahead/` の比較値は次の意味に限定する。

- 同一スナップショット、同一config上で方式を比較する代理指標
- `is_included`、`is_valid`、`is_placed_safe`が全ケースtrueのときだけ有効
- コンペの非公開scene、評価重み、完全な動的安定性を含むリーダーボード点ではない

ローカル比較が改善しても、コンペ総合scoreの改善とは断定しない。

## 6. 評価環境と投稿上の条件

- Ubuntu 24.04
- メモリ16 GB
- vCPU 4コア
- スクリーニング期間中の投稿上限は1日5回
- 最終評価では暫定評価とは別の評価sceneが用いられ、順位が変動し得る
- 最終評価に使う投稿ファイルは最大2つまで選択でき、高score側が採用される
- 同scoreの場合は応募日時が早い方を上位とする
- 上位10者程度を懸賞金候補者として選出する

課題ページの表示上の締切は `2026-10-19 23:55`。日程・提出条件・参加資格は
変更される可能性があるため、提出時にはSIGNATE上の最新表示を再確認する。
