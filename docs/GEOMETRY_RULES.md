# NEDO 配置幾何の単一仕様

## 1. 座標系

- `place_pos` と候補生成は、各コンテナのローカル座標を使う。
- `packed_items[*].pos`、`points`、`n_vecs` は世界座標として扱う。
- 公式シミュレーターの変換は X 軸のオフセットだけである。
  - local → world: `(x + container.center[0], y, z)`
  - world → local: `(x - container.center[0], y, z)`
- 変換は `local_to_world` と `world_to_local` 以外に書かない。

## 2. 棚の実寸

棚寸法は固定値にせず、`containers.py` の生成式から毎回計算する。

- 小棚
  - center: `(-L/2 + cut_x/2 + t, 0, H/2 + t/2 + buffer)`
  - size: `(cut_x, W - 2t, t)`
- 主棚（公式観測の `shelf=true`。内部では `require_shelf` へ正規化）
  - center: `(0, W/4, H/2 + t/2 + buffer)`
  - size: `(L - t, W/2 - 2t, t)`

`pi/2` の X 回転により、PyBulletへ渡した Y/Z の半寸法が世界座標では入れ替わる。

## 3. 配置後の物理落下

- 内部の `candidate` は支持面に接した最終姿勢を表す。
- 通常は `place_pos = candidate.center` とする。
- 公式搬入判定は通常、`place_pos` の8 cm上で水平搬入を検査する。
- ただし棚面から5 cm以内を目標にすると「直置き」と判定され、接触高さのまま水平搬入して棚と15 mm衝突になる。
- 棚上候補だけは `place_pos` を最終接触位置より5.1 cm上へ持ち上げる。搬入後、公式のsettle処理で棚面へ落下させる。
- 搬入開始高さは公式分岐をそのまま再現する。送信底面が床・棚から5 cm以内なら送信高さのまま、そうでなければ送信高さ+8 cmとし、天井余裕18 mmと上限10 mmでクリップする。
- 搬入経路は公式実装どおり、開口部から基準Xまで進むY軸区間と、そこから目標Xへ動くX軸区間の2本を別々に検査する。
- 既配置荷物は、settle後に観測されるクォータニオン `orn` から世界軸AABBを再計算する。要求した整数orientationをそのまま使わず、物理落下後の傾きを後続搬入へ反映する。
- 支持面は床、棚、または硬い既配置荷物。
- 支持面との垂直接触には15 mmの空間を要求しない。
- 底面積の55%以上が支持されない候補は拒否する。
- 軟らかい荷物は次の荷物の支持面にしない。

## 4. 安全マージン

- 境界面: 公式5 mmに、settle後の位置ずれ用10 mmとfloat32丸め用1 mmを加え、全角を16 mm内側に置く。
- 荷物・棚の側面と搬入経路: 公式15 mmにfloat32丸め用1 mmを加え、内部では16 mmを確保する。
- 搬入中はPyBulletの `getClosestPoints` に合わせ、横重なりだけでなく3次元AABB間のユークリッド最近接距離で16 mmを検査する。
- 支持面との垂直接触: 接触を許可する。

つまり公式の「15 mm」は支持面との垂直接触へ足す値ではなく、搬入経路の3次元最近接距離である。搬入実装値16 mmはfloat32丸め用の1 mmガードを含む。境界16 mmは別内訳で、公式5 mm＋settle位置ずれ10 mm＋丸め1 mmである。物理settle後の姿勢差は、観測 `orn` から実AABBを再構成して扱う。8 cmは通常搬入経路の開始高さであり、棚上だけは公式直置き判定を避ける5.1 cmの目標リフトを別に適用する。
