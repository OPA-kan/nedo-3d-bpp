# コンペ公式QA要約

**出典:** ユーザー提供の公式QA一覧(xlsx、2026-07-31受領)。原文の言い回しを
要約している。ルール本文は `docs/COMPETITION_RULES.md`、幾何実装値は
`docs/GEOMETRY_RULES.md` が正本。

## スコア構造に効くもの

- **積載数カットオフ**: 一定数以上コンテナに積載できていないと、
  **充填率スコア以外は 0 になる**。カットオフ値は非公開。
  → placed 数は単独指標ではなく、cog / stability / placement / soft の
  全成分を生かす**ゲート**。エピソード延命(転倒回避)の価値は
  スコア構造上、fill トレードオフより大きい側に倒れる。
- **総合点は個別要件評価の合成**(ハード/ソフト順序、優先手荷物配置など)。
  トレードオフを考慮して総合点が上がるように開発せよ、が公式回答。
  具体的な計算方法・パラメータ・重みは**非公開**(定性定義のみ公開)。
- **評価時に揺らしテストがある**。摩擦係数は配置時の荷崩れリスクと
  揺らしテストの安定性に効くと明言。
  → stability_score は静的配置でなく動的応答由来。`Phi_slide` の
  item 属性(lateralFriction 等)と滑り(d_xy)チャネルの優先度が上がる。

## 物理仮定の公式確認

- **手荷物は直方体前提、重心は対角線の交点**(一様密度)。
  → 力学特徴の z_com = z_rest + h/2 仮定は公式仕様に一致。
- **inclusion_margin は評価環境でも配布サンプルと同じ**(-0.005)。
  内壁に接するほど寄せて置かれた荷物は**充填率に算入されない**。
  → 壁ギリギリ配置は fill を失う。候補生成の壁マージンに影響。

## 運用ルール

- 一度積み付けた手荷物の**取り出し・コンテナ内移動は不可**。
- コンテナ外座標を指定してエピソードを終了させることは実装上可能だが
  非推奨(有利にならない想定)。
- 課題A/B/Cごとのアルゴリズム分割提出は**明示的には不可**。最初に渡される
  コンテナ・手荷物情報から**自動判別して切り替える**のは可。全課題に
  汎用的に動くこと。
- Python から呼べれば C/C++/Rust 実装・DLL も可(配布 Docker イメージで
  ビルドすること)。生成AIを用いた開発も可。知財は開発者帰属。
