# Trajectory-advantage value development

Source: the 25 valid H3/B3 physical graphs generated by Actions run
`32441630451` at commit `9ed7fa6`. All eight graph jobs passed. The aggregate
job failed only in the first version of the new exporter; commit `8fce14b`
fixed its reversed suffix-stack tuple. The fixed exporter was then run against
the downloaded immutable graph artifacts.

This is retrospective development evidence, not a prospective policy gate.

## Teacher contract

- 528 candidate-versus-rank-zero-incumbent rows;
- eight physical trajectory groups and 25 root graphs;
- 390 rows from roots below step 15 and 138 from roots at or above step 15;
- all 528 rows have paired action and physical afterstate tensors;
- zero action tensors contain `immediate_score`;
- all 20 independent outcome heads are present on all 528 rows.

## Whole-trajectory held-out result

The fixed-L2, no-intercept ridge predicts direct directed advantage in physical
outcome units. Every fold holds out the complete policy-generation × future-
stream × case × scenario group.

| head / view | directional correct | exact-unseen correct | reading |
|---|---:|---:|---|
| fill / action only | 266/295 (90.2%) | 248/276 (89.9%) | strongest signal |
| fill / PyBullet afterstate only | 228/295 (77.3%) | 228/295 (77.3%) | loses to action |
| fill / action + afterstate | 235/295 (79.7%) | 235/295 (79.7%) | loses to action |
| placed / action only | 8/14 (57.1%) | 8/13 (61.5%) | under-supported |
| horizon survival / action only | 8/14 (57.1%) | 8/13 (61.5%) | under-supported |
| soft / action + afterstate | 31/46 (67.4%) | 31/46 (67.4%) | diagnostic only |
| shake peak KE / action only | 188/322 (58.4%) | 179/303 (59.1%) | too weak for guard |

The fill class balance is 206 candidate-better versus 89 incumbent-better, so
an always-candidate rule scores 69.8%; the 90.2% action result is not explained
by that majority. It also excludes the old heuristic score, so this is a real
learned candidate-geometry signal.

The frozen development gate nevertheless fails because it required physical
afterstate value to improve on action-only value. More importantly, all 14
placed/survival directional examples come from one trajectory group. The
current corpus therefore cannot establish that using the strong fill signal
will preserve placed count or survival on an unseen trajectory.

## Decision

The direct paired target is retained. The old residual-affordance enforcement
remains rejected. The action-only fill head is a promising learning signal,
but it is **not yet a score-improvement agent** and must not be enforced.

The next physical experiment should not collect another identical H3 matrix.
It should force the action model's discordant candidate/incumbent pairs and
deepen only those pairs to H5, with multiple trajectory groups. Its admission
condition is placed/survival directionality in at least four independent
groups; only then can a constrained selector be evaluated without trading fill
against an unlearned death channel.
