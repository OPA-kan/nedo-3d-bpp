`scripts/fit_hazard_model.py` のデータ(7,619行 / 9ケース)を、エピソード
進行度(ケースごとに正規化)で層別して再フィットした。

| 相 | 行数 | 正例率 | step内 discordant-pair 精度 | ペア数 |
|---|---:|---:|---:|---:|
| 大域(係数1組) | 7,619 | 0.182 | 0.617 | 20,718 |
| 早期 0–33% | 3,189 | 0.001 | **測定不能** | **0** |
| 中期 33–66% | 2,861 | 0.134 | 0.573 | 12,820 |

## 符号が反転する特徴(16中3)

| 特徴 | 早期 | 中期 | 後期 |
|---|---:|---:|---:|
| `attempts_consumed_log` | +0.14 | +0.20 | **−0.51** |
| `deadline_reached` | +0.01 | +0.53 | **−0.29** |
| `reject_corridor_frac` | −0.10 | +0.26 | +0.41 |

大きさの変化も大きい: `settled_share` 0.00 → 0.56 → **1.28**、
`unit_coverage` −0.16 → **−1.71** → −1.47。

**大域フィットはこれらを平均する。**符号が反転する項は打ち消し合い、
「信号なし」に見える。盤面価値の試み3件(離散カウント / Φ / MC rollout)が
いずれも step 内で chance 水準だったことと整合する。

## 正直な区別(過剰主張を避けるため)

早期の測定不能は「予測が難しい」のではなく **正例が無い** — エピソードは
序盤で終わらないので、予測すべき事象そのものが存在しない。これは相依存の
**ラベル存在性**であって特徴重要度ではない。真に相依存なのは上の符号反転と
係数の大きさである。

## 設計上の帰結

Gated Iota が `μ_eff = μ·exp(−c·L_inv)` で「同値類が安定な所だけ幾何を
支える」のと同じ形で、盤面価値項は**信号が測定されている相でだけ開き、
無い相では閉じる**べきである。death-band gate は相を問わず発火していた。


## 出荷可能な相変数: `settled_share`(2026-08-04 検証)

後知恵の進行度(`step / 終端step`)は agent が計算できない。決定時点で
観測できる代理を探し、3つの検定を課した。

**検定1 — 同一ペア・LOSO(20,764 discordant pairs 共通)**

| モデル | step内精度 |
|---|---:|
| 大域(係数1組) | 0.617 |
| **相ゲート(係数2組、`settled_share` 中央値で分割)** | **0.679** |

**検定2 — 分割一般の効果ではないか**

| ゲート変数 | 大域比 |
|---|---:|
| `settled_share` | **+0.062** |
| `pool_size` | +0.033 |
| `release_accept_rate` | +0.019 |
| `unit_coverage` | −0.005 |
| `immediate_score` | −0.010 |

効かない変数は効かない。分割そのものの効果ではない。

**検定3 — 境界が当てはめ値でないか**

分位 0.3 / 0.4 / 0.5 / 0.6 / 0.7 → 0.689 / 0.685 / 0.679 / 0.688 / 0.657。
広い範囲で平坦なので、閾値を選んでいない。

**解釈**: `settled_share` は探索が settled 候補に割いた割合。低い =
盤面が settled 配置を提供しなくなり探索が release に移った = 詰まって
断片化した相。後知恵の進行度と +0.660 で相関するが、**決定時点で観測できる**。
